# AgentGuard

AgentGuard 是面向 AI 智能体工具操作的权限与审批工作台，用于管理操作范围、审核请求并追溯执行记录。

## 主要功能

- **任务权限**：为每项任务设置允许操作的范围。
- **操作预览**：在提交和审批前核对操作对象与拟写入内容。
- **人员审批**：按角色处理请求，高风险操作需独立审批。
- **执行跟踪**：批准与执行分开，查看完成、阻断或结果未知等状态。
- **审计核查**：查询操作记录与完整性核验结果。
- **云端说明**：通过华为云 AgentArts 辅助核对和解释请求，不替代审批。
