# AgentGuard

**面向智能体工具操作的权限与审批工作台。**

AgentGuard 将任务权限、操作请求、人员审批和执行记录集中在一个网页工作台中。用户可以设置任务允许的操作范围，核对请求内容，按角色处理审批，并查看执行结果与审计记录。

目前处于竞赛开发阶段。本仓库用于展示项目介绍；核心实现和完整技术材料暂不公开。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 任务与接入 | 为任务设置允许的操作范围，区分用户与智能体接入身份。 |
| 请求工作台 | 集中查看待处理请求、当前状态和最近操作。 |
| 操作预览 | 在提交和审批前核对操作对象及拟写入内容。 |
| 人员审批 | 按角色处理需要确认或独立审批的请求。 |
| 执行结果 | 将批准与执行分开，展示执行完成、阻断或结果未知等状态。 |
| 审计核查 | 查看事件记录与完整性核验结果，辅助追溯操作过程。 |
| 请求说明 | 通过华为云 AgentArts 提供只读核对与解释，辅助理解请求。 |

## 操作流程

1. **设置任务权限**：确定本次任务允许操作的范围。
2. **预览并提交请求**：核对操作对象、内容和相关说明。
3. **按角色处理审批**：需要审批时，由对应人员作出决定。
4. **继续执行**：批准后，由原发起身份另行发起执行。
5. **核对结果与记录**：查看执行状态和审计信息；结果未知时停止重试，先核查实际状态。

高风险请求需要独立审批。聊天中的同意或模型解释不构成执行授权。

## 网站与云端

- **网页工作台**：提供任务、请求、审批、执行结果与审计界面。
- **华为云 AgentArts**：用于请求核对及只读解释，不替代人员审批。
- **计划访问地址**：`https://duskrain.cn/agentguard`。域名路径接入尚待上线验收，当前不作为已开放的体验入口。

项目已有本地与部分云端集成验证。当前为范围受限的研究与演示原型，不代表通用安全保证或生产认证。
